# Security Policy

## Reporting a Vulnerability
At Spoonfed IT Solutions, security and client data privacy are paramount. If you discover a vulnerability or security issue within our codebases or configurations:

1. **Do not** open a public issue.
2. Email full technical details directly to security@spoonfed.it or notify Christian Witherspoon.
3. Include repro steps, affected components, and potential impact.

## Security Controls
- Organization-wide push protection & Gitleaks secret detection.
- All secrets managed through 1Password service tokens (op run).
- Continuous CVE and dependency scanning on all PRs.
